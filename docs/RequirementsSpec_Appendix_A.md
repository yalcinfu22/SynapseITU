## Appendix A — Gherkin Acceptance Scenarios (from the use-case document)

One Gherkin scenario per user story, quoted from Section 5 of the use-case document (the "/" separators of the source are kept); SC-FR rows are written from Section 2.1 of the main document. Notes (N), assumptions (A) and constraints (C) are the story's (or FR's) own; "—" means the source gives none. These scenarios are the test-first acceptance criteria of WBS-15.1 (pytest-bdd).

| User story / SC-FR | Title | Priority | WBS | Notes / assumptions / constraints | Gherkin scenario |

| US-01 | Register an account | Essential | WBS-1.1 | N: Registration needs name, e-mail, password and role. A: Admin accounts are created by the team, not by self-registration. | US-03 | Reset my password | Essential | WBS-1.1 | N: Changing the password revokes all tokens. C: The link expires after a short time and works once. | Given a user requested a reset / When the user sets a new password through a valid link / Then the password changes AND all old sessions end. |

*Note on quoted wording:* Some quoted notes keep wording that Issue 1 made measurable ("Short-lived JWT access token" in US-02, "a standard hashing algorithm" in US-01, "expires after a short time" in US-03, "sees it in real time" in US-29). The binding numerical requirements are NFR-01 (MC-01: ≤15 min), NFR-02 (MC-02: Argon2id), FR-07 (reset link expiry: 30 min) and NFR-28 (MC-15: ≤2 s if chat is implemented). Quoted goals such as "review applications faster" (US-26) and "review many applicants quickly" (UC-11 purpose) state the user's motivation, not a verifiable requirement; no performance target is derived from them.

**Requirements without a user-story scenario.** The DoD of WBS-16.1 asks that every Essential requirement have at least one Gherkin scenario. All 48 Essential user stories have one (above). At the finer level of Section 2.1, ten Essential functional requirements have no Gherkin scenario in the use-case document: FR-04, FR-13, FR-24, FR-27, FR-62 and FR-69, and FR-37, FR-42, FR-58 and FR-67, which were verified only through a Project Plan DoD. Their scenarios are the SC-FR rows above.
